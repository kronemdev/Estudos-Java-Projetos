## 📁 Projetos No Repositório

Aqui estão os projetos desenvolvidos até o momento, divididos por pastas:

### 🏦 [Caixa Eletrônico](./caixa-eletronico)
Um simulador de caixa eletrônico interativo que roda direto no terminal.
* **O que pratica:** Estruturas de repetição (`while`), decisões condicionais (`switch/case` e `if/else`), controle e limpeza de buffer do `Scanner`.
* **Funcionalidades:** Consulta de saldo real, depósito com soma acumulada e saque com validação de saldo insuficiente.

### 🧮 [Calculadora de Soma](./calculadora-soma)
Um sistema simples para realizar operações de soma com dados inseridos pelo usuário.
* **O que pratica:** Entrada e saída de dados (`System.in`/`System.out`), tipos primitivos numéricos e operadores matemáticos.
